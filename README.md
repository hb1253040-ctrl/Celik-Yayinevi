# Çelik Yayınevi

PHP ile geliştirdiğim, kitap satışı yapan bir e-ticaret web sitesi. Ziyaretçiler kitapları inceleyebilir, yönetici ise admin panelinden ürünleri yönetebilir.

## Özellikler
- Kitap (ürün) listeleme ve detay sayfası
- Admin paneli: ürün ekleme / düzenleme / silme
- *(Sadece gerçekten çalışanları bırak: sepet, sipariş, kullanıcı girişi, kategori, arama, ödeme vb.)*

## Kullanılan Teknolojiler
- PHP (kendi MVC yapısı)
- JavaScript
- Composer
- MySQL *(kullanıyorsan)*

## Proje Yapısı
- `App/` : Uygulama kodları
- `Core/` : Temel sınıflar
- `public/` : Dışarıya açık dosyalar

## Kurulum
1. `git clone https://github.com/hb1253040-ctrl/Celik-Yayinevi.git`
2. `composer install`
3. `config.example.php` dosyasını `config.php` olarak kopyala ve veritabanı bilgilerini doldur
4. Projeyi yerel sunucuda (XAMPP vb.) çalıştır
